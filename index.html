Simple, desde tu celular

1. Tocá WhatsApp en un negocio: se copia el catálogo (alterna solo) y se abre el chat con el mensaje. En el chat mantené apretado → Pegar → enviá.

2. Revisá el mensaje del sistema. Podés editarlo antes de abrir el chat.

3. Para enviar el catálogo, tocá “Compartir imagen + texto”, elegí WhatsApp y después el destinatario. La inclusión del texto depende del celular; “Copiar texto” queda disponible.

4. Para hablar, “Llamar” abre el marcador telefónico.

Los contactos y estados son una copia fechada de la base del proyecto. Las marcas que hagas acá se guardan solo en este navegador; no se sincronizan con la PC ni con otros celulares.
